# Research — the next frontier for neo-handcricket (Round 2)

Round 1 (M004–M008) made the core deep: realism, a reading AI, broadcast commentary, and a roguelite
career wrapper. Round 2 asks *what turns a good single-player game into one people return to daily and
recommend.* Survey below; sources at the bottom.

## 1. Daily-seed & procedural challenges
The "daily run" (Spelunky, Slay the Spire) is the cheapest high-retention mechanic in the genre: **one
deterministic seed shared by everyone for 24h**, producing the *same* match conditions + a small set of
modifiers, scored on a leaderboard so "the conditions were no more favourable or adverse for you than
anyone else." We already have **seeded RNG everywhere** and **offline share codes** — a daily challenge
is mostly a deterministic seed-from-date + a fixed config + a score function + a local best-table, with
results shareable via the existing `sharecode`. Fully offline (no server needed; the seed is derived
from the date, the leaderboard is local + copy-pasteable codes). → **M009**.

## 2. Accessibility & onboarding (a 1.0-worthy bar)
CLI accessibility has clear, well-documented standards we currently miss:
- **`NO_COLOR`** is a community-standard env var that must be honoured.
- **Redraw/animation-based UIs break screen readers**; offer a `--no-animation` / static, line-appended
  mode and an `--a11y` / `--simple` minimalist mode that drops boxes/ASCII art.
- **Colourblind-safe**: never encode meaning in colour alone (we lean on yellow/green/red) — pair with
  glyphs/text (we already use ★/💯/glyphs, good; extend).
- **Configurable timer** (our 3s hidden timer is hostile to slower/AT users) — already a config knob,
  surface it; add an "untimed" option.
- **Onboarding**: a short interactive tutorial + clearer first-run guidance lowers the bar; the genre
  drips mechanics in over early runs.
This bundle — accessibility + onboarding + a definitive polish pass — is the right **headline for
v1.0.0**. → **M010 (v1.0.0)**.

## 3. A reuse layer: headless adapter + optional TUI
A GUI/web port is the long-standing roadmap dream, but the guardrail is **offline-only / no network**.
The portable, guardrail-safe step is a **headless game adapter** — a thin, UI-agnostic API over the
existing pure engine (start match → submit pick → observe state) that *any* front-end can drive — plus an
optional **Textual TUI** (a richer terminal UI, still local, no network). This de-risks a future
browser/Tauri port (which would reuse the same adapter) without adding network/telemetry now. → **M011**.

## 4. Deeper roguelite: relics & run modifiers
Slay-the-Spire's depth comes from **relics** (permanent run-scoped rule-benders) and **drafted choices**
with real opportunity cost ("decline a card that dilutes the deck"). For cricket this maps to
**run-scoped modifiers/relics** drafted between tournament matches — e.g. "extra powerplay over",
"fatigue accrues twice as fast (for both)", "boundaries worth +1", "your tail bats like openers" — each
shifting the M005/M006 tunables we already expose. Pure, seeded, and composable with the M008 career.
→ **M012**.

## 5. Content & localization
Breadth: more **hand-curated rosters** for nations where the auto-generator reads off-rhythm, more
**commentary** (the bank is large but always wants depth), and a **localization scaffold** — parallel
`LINES`/string tables so the English-only commentary can be translated (structure now, translate later).
All CC0/original. → **M013**.

## Round 2 plan (M009–M013)
| Milestone | Theme | Version |
|---|---|---|
| **M009** | Daily-seed & procedural challenges (+ local leaderboard, share codes) | v0.9.0 |
| **M010** | Accessibility, onboarding & the **1.0 polish** pass | **v1.0.0** |
| **M011** | Headless adapter + optional Textual TUI foundation (local, no network) | v1.1.0 |
| **M012** | Roguelite draft: relics & run modifiers in the career | v1.2.0 |
| **M013** | Content & localization scaffold | v1.3.0 |

Arc: **give players a reason to return daily → make 1.0 accessible & polished → open the engine to new
front-ends → deepen the roguelite → broaden content/reach.** Each is one minor bump; **v1.0.0 lands at
M010**.
