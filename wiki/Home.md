# 🏏 neo-handcricket

A single-player CLI hand cricket game — five formats, 200 country rosters, and a 20-commentator
conversational engine. Built via a looped autonomous-dev cycle (see [[Roadmap]] · [[Release-Notes]]).

- **Play:** `neo-handcricket`
- **Source of truth:** the Obsidian vault in `docs/` (milestones, issues, ADRs); the GitHub Project
  board + issues are generated from it.
